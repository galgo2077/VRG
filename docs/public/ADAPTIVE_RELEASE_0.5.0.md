## Frozen synthetic A/B

30 technical documents, 12 small-change revisions retained equally, eight tasks, real MCP textual retrieval on both binaries with the same 512-byte excerpt bound. One hundred unchanged candidate indexings created no additional generation or object. All mandatory facts passed. The evaluator expands either variant when frozen task facts are absent; this quality oracle is not a claim of autonomous semantic sufficiency. All eight candidate partial-preview warnings remain visible.

| Measure | Baseline | Adaptive |
|---|---:|---:|
| Complete application context including used expansions, bytes | 30,137 | 17,348 |
| Complete MCP results including envelope, bytes | 31,854 | 18,887 |
| Complete MCP evaluation lexical units | 7,261 | 5,174 |
| Stabilized derived storage including SQLite/WAL/SHM and required files, bytes | 2,105,344 | 618,496 |
| Exact expansions | 8 | 2 |
| Maximum observed task latency, seconds | 0.872 | 0.826 |

Complete MCP context decreased 40.71% by bytes and 28.74% by evaluation units; derived storage decreased 70.62%. Evaluation units use fixed Unicode `\w+|[^\w\s]` lexical-v1, not billed Codex tokens. Model bytes and backups were zero for these fresh text-only fixtures; no file was excluded by moving it elsewhere. Peak child RSS was 325,432 KiB across the runner's children, not a per-variant peak. Filesystem peaks were sampled between commands; intra-command peak is unknown. Latency includes new MCP processes/handshakes; persistent warm-server latency and cold OS-cache latency were not measured.

Counted initial proposal preparation/input material was 2,960 evaluation units, and proposal output 2,603: 5,563 units total. Twenty-two queries is only an optimistic amortization bound for this same task mix and counted material. Actual model prompting/validation overhead, billed cost and cost per update are unknown; no exact net billed savings are claimed. Summaries were authored by Codex, not generated by the benchmark script.

## Limits and recovery

Only Linux x86_64 and Codex were in scope. The native/runtime and libc requirements, binary SHA-256, package verification and public downloads are listed with the release. The extracted Linux artifact passed synthetic setup/doctor/MCP, proposal/tier/archive/restore/maintenance and hybrid retrieval using an existing compatible local E5 model (one vector object). Model-backed smoke coverage does not establish universal Linux compatibility or general retrieval quality. No model is bundled.

ENOSPC and pre/post publication interruption cases use deterministic injected failures, not physical disk exhaustion, process kill or power loss. Offline-copy migration never promotes over a live legacy store. SQLite retention and COLD deletion are separate durable phases; a COLD failure can leave the already committed SQLite maintenance intact. Corrupt/unexamined archive data and protected data are preserved under capacity pressure. Doctor's bounded inspection does not certify objects it did not inspect.

Private source notes, session transcripts, local configurations, derived stores, models, backup files and detailed operational evidence are excluded from this public report and distribution.
