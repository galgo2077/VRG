# VRG roadmap and verification gates

The source distribution contains the Rust implementation and documentation for local builds. Validation is limited to the recorded local environment and cases; a successful source build does not certify a new deployment.

- **Local operation:** maintain explicit root permissions, privacy exclusions and rebuildable derived storage.
- **Website:** these static files can be reviewed locally; publishing a website requires separate hosting configuration.
- **Platforms:** macOS and Windows require separate validation before support can be claimed.
- **Distribution:** no packaged installer, hosted inference, cloud synchronization or third-party security audit is claimed.
