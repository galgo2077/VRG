VRG — Vault RAG Graph

LOCAL · CÓDIGO ABIERTO

Busca en tus notas.
Conserva los originales.

VRG crea un índice local de archivos Markdown autorizados. Permite buscar texto, utilizar recuperación semántica opcional y navegar enlaces sin mover ni reescribir las notas.

Guía de instalación ↗Código fuente ↗

Código publicado y binario Linux x86_64. No hay certificación para otras plataformas.

01 / PROYECTO

Qué hace VRG

Búsqueda de texto y semántica

Recuperación textual basada en SQLite/FTS5. Los embeddings locales son opcionales y requieren un modelo compatible.

Relaciones entre notas

Los enlaces derivados conectan documentos Markdown. Los archivos originales siguen siendo editables desde Obsidian u otro editor.

Integración MCP

Un servidor MCP local y de solo lectura expone búsquedas y referencias atribuidas a clientes compatibles, incluido Codex.

02 / INSTALACIÓN

Empieza por el paquete publicado.

Instala el crate actual, inicializa una configuración e inspecciona su estado. Antes de indexar, autoriza una raíz Markdown y separa el almacenamiento derivado.

Los comandos automáticos vrg setup y vrg doctor están previstos, pero aún no forman parte del release publicado.

Instalación y verificación completas ↗Binario Linux y hashes ↗
TERMINALLinux · Cargo
cargo install vrg --locked
vrg init
vrg status
Primero prueba con archivos sintéticos, no con tus notas personales.
03 / AYUDA

Errores comunes

Comprobaciones básicas para los problemas más frecuentes de instalación e integración.

01vrg: command not found

Comprueba que el directorio de binarios de Cargo, normalmente ~/.cargo/bin, está en PATH. Abre una terminal nueva y ejecuta vrg --version.

02Falla Cargo o la compilación

Comprueba la versión mínima de Rust y las herramientas nativas. Para compilar offline, las dependencias deben existir en caché. Identifica la biblioteca que falta leyendo el error concreto.

03VRG no aparece en el MCP de Codex

Revisa la configuración MCP efectiva, el ejecutable y las rutas absolutas. Abre una sesión nueva y consulta /mcp; deben aparecer cuatro herramientas de solo lectura.

04Hooks modificados o sin confianza

Abre /hooks, revisa los comandos exactos y apruébalos mediante Codex cuando corresponda. Instalar VRG no concede confianza automáticamente.

05sync_pending o índice desactualizado

Ejecuta vrg status y revisa la generación y los permisos de las raíces. No presentes resultados obsoletos como actuales; comprueba el watcher o realiza una indexación deliberada.

06Falta el modelo semántico

La búsqueda textual funciona sin modelo. Para habilitar semántica, suministra un modelo ONNX compatible y sus archivos de tokenización desde una fuente verificada.

07El ejecutable Linux no inicia

El binario x86_64 publicado requiere bibliotecas compatibles de glibc y libstdc++. Si tu sistema es antiguo, compila desde fuentes en lugar de reemplazar bibliotecas del sistema.
