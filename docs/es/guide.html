01 / PRESENTACIÓN

¿Qué es VRG?

VRG (Vault RAG Graph) es un proyecto en Rust para recuperar conocimiento de fuentes Markdown autorizadas, manteniendo editables los originales y construyendo índices derivados de texto, semántica y relaciones.

Acceso deliberadoRaíces permitidas y exclusiones explícitas.
Contexto precisoFuentes atribuibles y revisiones verificables.
Memoria selectivaDecisiones verificadas, no transcripciones.

02 / PRIMEROS PASOS

Primero el código.

Compila el código publicado siguiendo la guía de instalación. Todavía no hay un instalador empaquetado.

Puedes inspeccionar el material público:

$ git clone https://github.com/galgo2077/VRG.git

Este comando solo clona lo publicado; no instala el runtime certificado.

04 / PRIVACIDAD

Local no siempre significa privado.

Un MCP local puede devolver fragmentos a un modelo remoto. Esta transferencia requiere autorización independiente de la indexación.

  • Sin acceso implícito a todo el directorio personal.
  • Notas originales, credenciales y respaldos fuera de Git.
  • SQLite, embeddings y memoria técnica como derivados privados.
  • Revisar los hooks antes de confiar en ellos.
  • No almacenar conversaciones por defecto.

Estos son límites de diseño, no una auditoría externa.

06 / PREGUNTAS

Preguntas frecuentes.

¿VRG sustituye Obsidian?

No. El diseño conserva los Markdown originales y construye derivados.

¿Guarda conversaciones?

No como memoria predeterminada; busca documentación selectiva.

¿Funciona en macOS y Windows?

La vista preliminar no afirma compatibilidad validada en esas plataformas.

¿Ya puedo instalarlo?

El código puede compilarse localmente según la guía; no se afirma la existencia de un instalador empaquetado.
