01 / OVERVIEW

What is VRG?

VRG (Vault RAG Graph) is a Rust-based local-first approach to knowledge retrieval over approved Markdown sources. It is designed to preserve the original files while constructing rebuildable text, semantic and graph indexes for search and navigation.

Read deliberatelyAccess is limited to approved roots with explicit exclusions.
Recover preciselyFind context with attributable references and source revisions.
Remember selectivelyPrefer concise verified decisions to chat transcripts.

02 / GETTING STARTED

Start with the source.

Build from the published source using the documented Rust toolchain and locked dependencies. There is no packaged installer yet.

You can inspect the public materials now:

$ git clone https://github.com/galgo2077/VRG.git

Cloning does not install or certify a runtime for your machine.

See the installation guide for requirements, configuration, optional embeddings, MCP and hook review.

Codex / MCP

Codex is currently the only officially supported assistant integration. VRG can be used locally from its CLI without Codex; support for other AI clients has not been validated.

The published source can be inspected and built locally under the documented requirements.

04 / SECURITY

Local does not automatically mean private.

VRG can index Markdown locally and run a local MCP server. If the assistant receiving the retrieved snippets uses a remote model, those excerpts can enter its remote context. That transfer requires a separate, explicit decision.

  • Never grant implicit access to an entire home directory.
  • Keep original notes, private backups and secrets outside the public repository.
  • Treat SQLite indexes, embeddings, project memory and hook trust state as private derived data.
  • Review hooks and their commands before trusting them.
  • Do not save full prompts and conversations as default project memory.

These are design and policy boundaries, not a claim of third-party security certification.

06 / FAQ

Common questions.

Does VRG replace Obsidian?

No. The design keeps original Markdown editable. VRG manages derived retrieval structures.

Does it store my chats?

Not as a default memory strategy. The intended approach is selective project documentation.

Are macOS and Windows supported?

The public preview makes no verified support claim for either platform. Support will be documented only when tested.

Can I install it today?

The source can be built locally; follow the installation guide. No packaged installer is claimed.
