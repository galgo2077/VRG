VRG — Vault RAG Graph

LOCAL-FIRST · OPEN SOURCE

Search your notes.
Keep the originals.

VRG builds a local index of approved Markdown files. Search text, optionally use semantic retrieval, and navigate links without moving or rewriting your notes.

Installation guide ↗Source code ↗

Released source and Linux x86_64 archive. Other platforms are not certified.

01 / OVERVIEW

What VRG does

Text and semantic search

Full-text retrieval backed by SQLite/FTS5. Optional local embeddings can expand matching when a compatible model is installed.

Note relationships

Derived links connect related Markdown documents. Source files remain editable in Obsidian or any text editor.

MCP integration

A local, read-only MCP server exposes attributed search and source references to compatible clients, including Codex.

02 / INSTALLATION

Start with the published package.

Install the current crate, initialize a configuration, then inspect its status. Before indexing, explicitly authorize a Markdown root and choose a separate directory for derived data.

03 / HELP

Common issues

Basic checks for the most frequent installation and integration problems.

01vrg: command not found

Confirm that Cargo's binary directory is on your PATH (usually ~/.cargo/bin). Reopen your shell and run vrg --version.

02Cargo build or installation fails

Check that Rust meets the package's minimum version and native build tools are installed. For an offline build, dependencies must already exist in the Cargo cache. Use the exact error message to identify the missing library.

03MCP tools do not appear in Codex

Review the effective project MCP configuration and absolute executable path. Start a fresh session and inspect /mcp; the server should expose four read-only tools.

04Hooks show modified or untrusted

Open /hooks, review the exact commands and approve them through Codex if appropriate. Installing VRG does not grant hook trust, and the example observer has its own portability limits.

05Index is stale or synchronization pending

Use vrg status to inspect the active generation and root permissions. Do not treat a stale generation as current; troubleshoot the watcher or perform a deliberate reindex.

06Semantic model unavailable

Text-only search works without a model. For semantic search, supply a compatible ONNX model and tokenizer files from a verified source; VRG does not download them by default.

07Linux executable does not start

The published x86_64 artifact has glibc/libstdc++ requirements. If your system is older or incompatible, build from source in your environment instead of replacing system libraries.
