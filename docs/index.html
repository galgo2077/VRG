BUILT AROUND BOUNDARIES

Your notes stay yours.

Markdown remains editable. Derived storage stays separate. A local MCP server does not make a remote AI model local—sharing retrieved snippets requires an explicit policy decision.

03 / PRINCIPLES

Private by
intent.

Access must be deliberate. Knowledge should be selective. Original files should remain under the owner's control.

Security philosophy ↗
01Explicit permission

Never assume every file in a home directory is eligible for indexing.

02Rebuildable derivatives

Keep indexes separate from source Markdown and preserve recovery paths.

03Compact knowledge

Document verified decisions, not entire prompts, conversations or raw logs.

04Honest release status

Publish only features and platforms supported by released, testable artifacts.
