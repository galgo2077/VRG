# Implementation contract

Implement setup and doctor in the public distribution without access to the development checkout or private notes. Source roots, memory writes, downloads and remote transfers are separate authorizations. Use official Codex project configuration and preserve unrelated settings and user-owned content. Hook approval remains a user action. Embed required integration resources and identify their version. Keep MCP read-only and use the same explicit profile for MCP and hooks.

Plans and dry runs do not write, download or index. Applications must detect external changes, use private backups, avoid duplicate entries, and provide safe recovery. Diagnostics are passive unless an explicitly requested isolated runtime probe is used; repairs operate only on recognized owned state. Offline mode makes no network requests. Verify a local semantic model or an explicitly consented pinned download rather than silently claiming semantic capability.

Validate S01–S11 with isolated synthetic inputs, preserving historical F4 and Zafiro evidence. Publish only after package, binary, documentation, runtime integration and installation have been verified against the exact new revision.
